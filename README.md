# Portfolio V2 — Lucas Epherra

Portfolio profesional bilingüe construido con Next.js, React, TypeScript y Tailwind CSS.

## Stack

- Next.js con App Router.
- React.
- TypeScript estricto.
- Tailwind CSS v4.
- ESLint.
- pnpm.

## Rutas base

- `/en`: versión en inglés.
- `/es`: versión en español.
- `/`: redirección permanente a `/en`.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Validación

```bash
pnpm typecheck
pnpm lint
pnpm build
```

El portfolio anterior se utiliza únicamente como inventario de contenido y referencia visual. No se migra su código ni condiciona esta arquitectura.
